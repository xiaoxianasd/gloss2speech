## 一、开干前必做：同步最新 `main`

请两位 Fork 协作者先同步主仓库最新代码，再各自拉新分支开发（不要在旧基线上直接改代码）：

```bash
# 仅首次需要绑定主仓库为 upstream
git remote add upstream https://github.com/xiaoxianasd/gloss2speech.git

# 每次开新任务前同步
git fetch upstream
git checkout main
git merge --ff-only upstream/main
git push origin main

# 基于最新 main 切出自己的功能分支
git checkout -b feat/你的任务名
```

> 本地一键启动直接双击根目录 `start.bat`（前端 `http://127.0.0.1:5173`，后端文档 `http://127.0.0.1:8000/docs`）。

     - 在华为云 **ModelArts Studio（MaaS）** 开通视觉模型（如 Qwen-VL 系列）和文本模型（如 DeepSeek 系列），创建 `MAAS_API_KEY`，核对控制台「调用说明」中的 `MAAS_BASE_URL` 和 `model` 名；

     - 运行 `python scripts/probe_cloud.py --runs 5 --all`，验证 LLM / VL / TTS / ASR 四路全部连通无报错，将生成后的 `reports/cloud_probe.md` 提交至仓库。

     - 准备华为云 ECS + 域名 + SSL 证书，按 `deploy/README.md` 构建前端并启动 Docker Compose；

- **验收标准（DoD）**：
  - `GET /api/health` 返回 `vision: "maas"`、`llm: "maas"`、`sis: "hwcloud"`；
  - `reports/cloud_probe.md` 四项均已实测并填入真实 P50/P95/P99；
  - 公网 `https://域名` 下手机与电脑可正常打开摄像头、麦克风、完成口令鉴权与完整双向翻译。

   ```bash
   python -m pytest -v
   node --test frontend/tests/roi.test.mjs research/fastpath-frontend/tests/sign-core.test.mjs
   cd frontend && npm run build
   ```
   确认全部通过后再提 PR 到 `xiaoxianasd/gloss2speech` 的 `main`。
